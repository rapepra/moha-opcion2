========================================================================
CARPETA DE IMÁGENES - MOHAUS
========================================================================

Aquí puedes colocar todas las fotografías reales de tus instalaciones,
fontanería, climatización, aerotermia, calefacción y reformas.

El archivo `index.html` ya está configurado para mostrar y priorizar estas
imágenes. Solo tienes que arrastrar tus fotos a esta carpeta y renombrarlas:

------------------------------------------------------------------------
📸 NOMBRES DE ARCHIVO RECOMENDADOS PARA LA WEB Y GALERÍA:
------------------------------------------------------------------------
1. `trabajo-fontaneria-1.jpg`    -> Instalaciones de fontanería y colectores
2. `trabajo-aerotermia-1.jpg`    -> Unidad de aerotermia o bomba de calor
3. `trabajo-clima-1.jpg`         -> Instalación de aire acondicionado
4. `trabajo-calefaccion-1.jpg`   -> Montaje de radiadores / caldera
5. `trabajo-bajante-1.jpg`       -> Sustitución de bajante PVC insonorizado
6. `trabajo-desatasco-1.jpg`     -> Desatasco técnico con maquinaria
7. `trabajo-bano-1.jpg`          -> Renovación complementaria de baño
8. `trabajo-cocina-1.jpg`        -> Renovación complementaria de cocina

------------------------------------------------------------------------
⭐ IMÁGENES GENERALES Y LOGOTIPO (OPCIONAL):
------------------------------------------------------------------------
- `logo.png`                     -> Logotipo de MOHAUS (fondo transparente)
- `equipo-mohaus.jpg`            -> Foto del profesional / equipo MOHAUS
- `furgoneta-herramientas.jpg`   -> Taller móvil y herramientas
- `og-image.jpg`                 -> Imagen para compartir en WhatsApp (1200x630 px)

------------------------------------------------------------------------
💡 CONSEJOS PARA MEJOR RENDIMIENTO:
------------------------------------------------------------------------
- Formatos recomendados: `.webp`, `.jpg` o `.png`.
- Si una foto no existe en la carpeta, la web cuenta con fallbacks visuales
  con degradados modernos y patrones para que siempre luzca impecable.
